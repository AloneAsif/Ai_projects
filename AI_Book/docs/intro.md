# Humanoid Robotics with ROS 2, Isaac Sim, and Navigation

## Welcome to the Robotic Nervous System

Welcome to the comprehensive guide on ROS 2 (Robot Operating System 2) fundamentals, Isaac Sim simulation, and navigation for humanoid robot control. This educational curriculum covers the essential concepts needed to understand and implement ROS 2-based robotic systems, RTX-accelerated simulation environments, and advanced navigation techniques, with a focus on nodes, topics, services, Python (rclpy), URDF basics, physics simulation, sensor modeling, VSLAM, and high-fidelity visualization.

## What You'll Learn

This curriculum is structured into three main modules:

### Module 1: ROS 2 Fundamentals
1. **[ROS 2 Overview](./ch1-ros2-overview.md)** - Understanding ROS 2 as a robotic nervous system, exploring nodes, topics, services, and actions with visual diagrams.

2. **[Hands-On ROS 2 (rclpy)](./ch2-hands-on-ros2.md)** - Practical implementation of ROS 2 communication patterns with runnable Python examples.

3. **[Python AI Agent → ROS Bridge](./ch3-ai-agent-ros-bridge.md)** - Connecting AI agents with ROS systems for intelligent robot control.

4. **[URDF for Humanoids](./ch4-urdf-humanoids.md)** - Creating humanoid robot models using Unified Robot Description Format.

### Module 2: Digital Twin Simulation
5. **[Digital Twin Fundamentals](./ch5-digital-twin-fundamentals.md)** - Understanding digital twins for humanoid robots, with complementary roles of Gazebo and Unity.

6. **[Gazebo Physics Simulation](./ch6-gazebo-physics-simulation.md)** - Physics simulation with gravity, friction, collisions, and humanoid spawning.

7. **[Sensor Simulation](./ch7-sensor-simulation.md)** - LiDAR, depth cameras, and IMU simulation with ROS 2 integration.

8. **[Unity High-Fidelity Digital Twin](./ch8-unity-digital-twin.md)** - High-fidelity visualization and human-robot interaction with Unity-ROS bridge.

### Module 3: Isaac Sim VSLAM and Navigation
9. **[Isaac Sim Setup Guide](./isaac-sim/tutorial-basics/setup.md)** - Prerequisites and installation for Isaac Sim environment.

10. **[Quick Reference](./isaac-sim/tutorial-basics/quick-reference.md)** - Common commands and parameters for Isaac Sim workflows.

11. **[Isaac Sim Perception Fundamentals](./isaac-sim/ch1-perception-fundamentals.md)** - RTX-accelerated simulation and synthetic data generation.

12. **[Isaac ROS VSLAM Pipeline](./isaac-sim/ch2-vslam-pipeline.md)** - Visual SLAM implementation with stereo and RGBD sensors.

13. **[Nav2 Navigation for Humanoids](./isaac-sim/ch3-nav2-navigation.md)** - Path planning with humanoid-specific constraints.

## Prerequisites

- Basic programming knowledge in Python
- Understanding of robotics concepts (helpful but not required)
- ROS 2 Humble Hawksbill or Iron Irwini installed on your system

## Getting Started

Begin with the [ROS 2 Overview](./ch1-ros2-overview.md) chapter to understand the fundamental concepts, then proceed through the hands-on examples to gain practical experience with ROS 2 development. After completing Module 1, continue with Module 2 to learn digital twin simulation techniques.

Each chapter includes theoretical explanations, practical examples, and integration with AI agents, all designed to be reproducible and graduate-level friendly.
